# F1 Data Dashboard

A Python desktop application for analysing Formula 1 race data using Python.

This project explores race performance, lap times, and driver comparisons through an interactive GUI.

## Features to be implemented

- Load Formula 1 race data from CSV datasets
- Analyse lap times and driver performance
- Visualise trends using matplotlib charts
- Interactive desktop GUI built with Tkinter
- Data analysis with pandas and NumPy
- Optional SQLite storage for querying data

## Technologies used

- Python
- Tkinter
- pandas
- NumPy
- matplotlib
- SQLite
- Git / GitHub

## Project Structure
- src/gui        -> Tkinter interface
- src/analysis   -> data analysis and processing
- src/database   -> SQLite database logic
- data/raw       -> source datasets
- data/processed -> cleaned data
- notebooks      -> experimentation and exploration
